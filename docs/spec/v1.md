# Spec v1: Lofi Lobby

The detailed design behind the [Architecture section of the README](../../README.md#architecture). Decisions in [ADR 001](../adr/001-one-durable-object-per-room.md) to [ADR 004](../adr/004-original-art-in-the-repo-local-assets-ignored.md).

## Flows

**Join.** The page loads the scene and shows "choose your trainer". The click on **enter the room** starts the radio (browsers need a gesture for sound). The client opens `wss://<host>/ws/<room>` and sends `ola { nome, genero }`. The room answers `voce { id }`, the current `radio { comando }` if any, and `estado { jogadores }`; everyone else gets `entrou`.

**Walk.** The client moves locally (collision runs on the client) and sends `pos { x, z, dir, passo }` at most 15 times a second, only when something changed. Others interpolate toward the last position.

**Chat.** `chat { texto }` → the room cleans it and sends `chat { id, nome, texto, em }` to everyone, sender included. The client adds it to the history and shows a bubble over the speaker for about 4 s (longer for long messages).

**Radio.** See [ADR 002](../adr/002-radio-synced-by-the-clock.md). Admin sends `radio { idx, senha }`; on success the room stores and broadcasts `radio { comando: { idx, em } }`; on failure it answers `erro { msg }` to the sender only.

**Leave.** On close or error the room broadcasts `saiu { id }`.

## Protocol

JSON over WebSocket, documented at the top of [`worker/index.js`](../../worker/index.js). Field names are short and stable; the server validates every one.

| From client | Fields | Server checks |
|---|---|---|
| `ola` | `nome`, `genero` | name cleaned to 16 chars; trainer is `masculino` or `feminino` |
| `pos` | `x`, `z`, `dir`, `passo` | finite, within ±500; `dir` in a list; `passo` 0–3 |
| `chat` | `texto` | cleaned to 140 chars; empty is dropped |
| `nome` | `nome` | as in `ola` |
| `genero` | `genero` | as in `ola` |
| `radio` | `idx`, `senha` | constant-time password check, 5 tries per connection |

## Limits

| Limit | Value |
|---|---|
| Players per room | 40 |
| Message size | 1 KB |
| Rate (bucket size / refill per s) | pos 30 / 20 · chat 5 / 0.5 · other 10 / 1 |
| Name / chat | 16 / 140 characters |
